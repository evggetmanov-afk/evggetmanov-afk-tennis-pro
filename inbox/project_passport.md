Контекст проекта: Тренировочный счетчик для iPad Pro (Web / PWA)
1. Цель и сценарий использования
Разработка автономного интерактивного счетчика игровых событий для тренировок на iPad Pro:

- На экране отображаются 6 крупных кнопок (по числу игроков).
- 
- Игрок после выполнения игрового действия подходит и касается своей кнопки.
- 
- При нажатии значение счетчика мгновенно увеличивается, раздается отчетливый звуковой сигнал (бип/тон).
- 
- По завершении серии/упражнения тренер может нажать кнопку отправки: результаты формируются в сводку и отправляются в Telegram-канал (через Telegram Bot API либо прямым fallback-переходом в Telegram при отсутствии сети).
- 
2. Архитектура и ограничения
- Монолитная структура: Весь проект ведется строго в одном файле index.html (инлайн CSS, инлайн JS, синтез звуков через Web Audio API без внешних медиафайлов).
- 
- Среда выполнения: Safari на iPad Pro, запуск через ярлык «На экран "Домой"» (режим Web App без рамок браузера).
- 
- Специфика iPadOS / iOS:
- 
  - Запрещено прямое открытие через протокол file:// (Safari изолирует окружение и намертво блокирует сетевые вызовы fetch() к Telegram API).
  - 
  - Требуется обязательная разблокировка AudioContext по первому тач-событию (touchstart / touchend).
  - 
  - Для исключения задержек интерфейса (300ms tap delay) и блокировок жестов используются нативные тач-обработчики (touchstart с { passive: false }).
  - 
  - Устройство не должно находиться в аппаратном Silent Mode (перечеркнутый колокольчик глушит Web Audio API).
  - 
3. Пайплайн разработки и развертывания
- Локальная разработка: macOS (терминал, Git).
- 
- Хостинг / Доставка на устройство: Бесплатный публичный репозиторий на GitHub с включенным GitHub Pages (ветка main, корень /).
- 
- Рабочий цикл:
- 
  1. Правки вносятся на Mac в index.html.
  2. 
  3. Пуш в удаленный репозиторий: git commit -am "..." && git push.
  4. 
  5. GitHub Pages пересобирает страницу за 30–60 секунд.
  6. 
  7. На iPad Pro страница открывается по ссылке https://<user>.github.io/<repo>/ и работает в автономном режиме на корте.
  8.
