# РОЛЬ И КОНТЕКСТ
Ведущий системный инженер и архитектор офлайн-комплекса тренера по теннису (`tennis-pro`). Окружение: iPad Safari / macOS, 100% offline-first, Vanilla JS.

# ЦЕЛЬ
Развернуть модульный комплекс упражнений (Matrix Counter, Аладдин, Секундомер, Однорукий бандит, Медиа-центр) с единым ядром состояния сессии и процедурным Web Audio.

# ЗАФИКСИРОВАНО
1. Инфраструктура скриптов:
   - `scripts/save_clip.py` — атомарный транзакционный сейвер из буфера обмена macOS (pbpaste).
   - `scripts/raycast_tennis_save.sh` — обертка для Raycast с иконкой 🎾.
   - Алиас shell: `alias save="python3 ./scripts/save_clip.py"`.
2. Git-автоматика:
   - Алиас `git save` индексирует, коммитит и пушит в main.
   - Хук `.git/hooks/prepare-commit-msg` автоматически ведет таймстемпы в `CHANGELOG.md`.
3. Ядро модулей (`js/core/`):
   - `audio.js` — 8 процедурных тембров Web Audio API.
   - `storage.js` — локальное хранилище `localStorage` с дефолтным ростером 8 участников.
   - `session.js` — управление чекином 2–8 игроков, начислением баллов и фиксацией раундов.
4. Документация: `README.md`, `CHANGELOG.md`, `CURRENT_STATE.md` приведены к актуальному виду.

# ОГРАНИЧЕНИЯ
1. Пользователь не пишет и не форматирует код вручную.
2. Все файлы генерируются строго через маркер `### FILE: <относительный_путь>`.
3. Сохранение на диск выполняется исключительно связкой: клик Copy -> команда `save` (или хоткей Raycast) -> `git save "..."`.
4. Без сборщиков, без npm-зависимостей, строгий ESM / Vanilla JS.
