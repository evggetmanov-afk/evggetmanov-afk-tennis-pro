## Временные технические договоренности
- Архитектура: 100% Offline-first, Zero-Dependency, единый монолит `index.html`.
- Сенсорный ввод: `pointerdown`, аппаратный троттлинг 110 мс по `pointerId`, `touch-action: manipulation`.
- Звук: процедурный Web Audio API без внешних аудиофайлов.
- Пакетные правки внедряются единым шагом через обновление `src/` и компиляцию через `scripts/build.py`.
