# ТЕКУЩИЙ СРЕЗ ПРОЕКТА: TENNIS PRO

## 1. Контекст и правила работы
- **Проект:** Автономный офлайн-комплекс для iPad тренера по теннису.
- **Рабочая папка:** ~/tennis-pro/
- **Стиль ведения:** Ведущий процесс — ИИ. Пользователю выдается строго готовая строка для терминала с командой `git save "..."`.
- **Автоматика:** Хук Git сам пишет время и сообщение коммита в `CHANGELOG.md`.

## 2. Что уже создано и работает (Фундамент)
1. `README.md` — кодекс разработки и правила проекта.
2. `CHANGELOG.md` — автоматический журнал хронологии.
3. `.git/hooks/prepare-commit-msg` — хук автоматического логирования.
4. `js/core/audio.js` — модуль Web Audio на 8 процедурных тембров.
5. `js/core/storage.js` — модуль `localStorage` (ростер 8 детей по умолчанию, активная сессия, экспорт бэкапа).

## 3. Состояние входящих документов
- В `01_Входящие/`:
  - `training_counter.html` (донор верстки табло и модалок).
  - `plan_modular_training_system.md` (план из 7 этапов).
  - `adr_002_training_management_system.md` (архитектурный стандарт).
- В `06_Архив/`:
  - Убран черновой дубликат `adr_002...`.

## 4. СЛЕДУЮЩИЙ ШАГ В НОВОМ ЧАТЕ
- **Модуль сессии:** создать `js/core/session.js` (управление чекином 2–8 детей, начисление очков в корзину дня, фиксация раундов).
- Затем сборка базового экрана `index.html` для проверки на iPad/Mac.
