# Спецификация требований: Тренировочный счетчик

## 1. Среда и инфраструктура
- **Форм-фактор:** Монолитный файл `index.html` (HTML5, CSS3, ES6 JS, Web Audio API, Canvas) без внешних фреймворков и библиотек.
- **Хостинг и доставка:** GitHub Pages (HTTPS), запуск на iPad Pro в полноэкранном режиме Web App («На экран "Домой"»).
- **Офлайн-автономность:** Полное функционирование логики, графики и синтеза звука без подключения к сети. Хранение профилей и состояния в `localStorage`.

---

## 2. Управление составом (Ростер и Чекин)
- **База участников:** Хранение постоянного списка группы в памяти устройства. У каждого участника:
  - Имя/Фамилия.
  - Аватарка (выбор из встроенной библиотеки ярких персонажей/животных).
  - Персональный забавный звук (уникальный мультяшный тембр).
- **Чекин перед занятием:** Быстрый выбор присутствующих галочками перед стартом.
- **Динамический состав серии:** От 2 до 8 активных участников. Кнопки отсутствующих на экране не отображаются.

---

## 3. Эргономика экрана упражнения
- **Сетка карточек:** Адаптивная центрированная компоновка под число участников (без избыточного раздувания на весь экран).
- **Карточка участника:**
  - Крупная контрастная аватарка.
  - Читаемое имя.
  - Большое табло текущих очков.
  - Цветовой акцент рамки.
- **Механика нажатия:**
  - Обработка через `touchstart` (исключение задержки 300 мс).
  - Проигрывание индивидуального звука при касании.
  - Защита от дребезга и повторного тапа (debounce 0.5–0.7 сек).
- **Контроль тренера:** Кнопка «Отмена» (Undo) для мгновенного снятия ошибочно начисленного очка с указанием имени игрока.

---

## 4. Режимы завершения серии
- **Общий таймер:** Настраиваемый обратный отсчет (вкл/выкл, выбор времени) с финальным звуковым сигналом.
- **Лимит очков (Target Score):** Игра до заданного числа очков (10, 12, 15, 21) с возможностью отключения.
- **Ручная остановка:** Кнопка завершения серии тренером в любой момент.

---

## 5. Итоги и медиа-дистрибуция
- **Экран рейтинга (Подиум):**
  - Блокировка дальнейшего ввода очков после завершения серии.
  - Автоматическое ранжирование участников по набранным баллам (1, 2, 3 места и далее).
- **Канал Telegram:** Прямая отправка отформатированного текстового отчета через Telegram Bot API в 1 клик.
- **Instagram / Facebook / Мессенджеры:**
  - Автоматическая генерация графической открытки для Stories (формат 9:16 через HTML5 Canvas: подиум, аватарки, счет, дата).
  - Нативный вызов системного меню «Поделиться» (Web Share API) для отправки в соцсети.
