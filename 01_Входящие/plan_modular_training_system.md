# Детальный план реализации: Модульный комплекс «Теннисный Полигон»

---

## Этап 1. Фундамент: Ростер участников, сессия и Главный пульт

### 1.1. Модуль базы участников (Roster Manager)
* **Интерфейс профиля:**
  * Список всех учеников группы с отображением статуса (в зале / отсутствует).
  * Экран добавления и редактирования профиля:
    * Ввод и изменение имени (с экранной клавиатуры iPad).
    * Загрузка фото: выбор файла из галереи iPad или прямой снимок с камеры.
    * Фоновое сжатие фото через HTML Canvas (до 300x300 px, JPEG 0.75, DataURL) для экономии места в localStorage.
    * Выбор персонального цвета рамки/акцента.
    * Выбор звукового пресета с кнопкой предпрослушивания.
* **Хранение данных:**
  * Ключ `tennis_roster_v1` в localStorage.
  * Начальная инициализация дефолтной группой (8 участников), если база пуста.
  * Экспорт всей базы в JSON и импорт из JSON (резервная копия на случай сброса кэша Safari).

### 1.2. Механизм тренировочной сессии (Session State Machine)
* **Структура активной сессии:**
  * Ключ `tennis_active_session_v1`.
  * Поля: ID сессии, дата/время старта, статус (`active` / `completed`).
  * `active_players`: массив ID выбранных на чекине детей (от 2 до 8 человек).
  * `totals`: объект суммарных баллов `{ [player_id]: number }`.
  * `history`: массив завершенных упражнений с детализацией.
* **Чекин перед тренировкой:**
  * Быстрый переключатель в главном меню: включить/выключить ребенка из сегодняшней группы в один тап.

### 1.3. Архитектура Главного меню (Dashboard Hub)
* Единая точка входа (`index.html`):
  * Шапка: Текущая дата, количество присутствующих детей, кнопка «Итоги дня».
  * Информер общего зачета: мини-таблица текущих лидеров дня.
  * Сетка карточек запуска модулей:
    1. Табло касаний (Счетчик попаданий)
    2. Секундомер с контролем ошибок
    3. Аладдин (Сбор мячей)
    4. Однорукий бандит (Слот-автомат ОФП)
    5. Экспертная машина (Техосмотр роботов)
    6. Настройки ростера и группы

## Этап 2. Апгрейд модуля «Табло касаний» (Touch Matrix)

### 2.1. Визуальный отклик и эргономика для iPad
* **Вспышка касания:**
  * Увеличение длительности импульса с 120 мс до 250 мс.
  * Полная плотная заливка фона карточки персональным цветом игрока с ярким свечением.
  * Кинетическая отдача: сжатие в момент тапа и упругий отскок.
* **Визуализация участника:**
  * Крупное центрированное отображение фото/аватарки (размер 90-100 px).
  * Высококонтрастный счетчик очков, читаемый с 7 метров.
* **Название упражнения:**
  * Крупная плашка с названием текущего задания над сеткой карточек.
  * Тап по плашке открывает быстрый выбор из списка шаблонов либо ввод своего названия с клавиатуры.

### 2.2. Уникальный звуковой синтез (Web Audio)
* Разработка 8 различимых по тембру и частотному диапазону процедурных звуков:
  1. Cat (мяуканье)
  2. Laser (космический выстрел)
  3. Spring (пружина Mario)
  4. Coin (чистый звон монеты)
  5. Bark (отрывистый щелчок/лай)
  6. Bubble (глубокий бульк)
  7. Chord (мажорное трезвучие)
  8. Chiptune (8-битный арпеджио-всплеск)

### 2.3. Интеграция с общей корзиной
* Кнопка «Завершить раунд» фиксирует очки серии, плюсует их в `total_scores` активной сессии, сохраняет запись в журнал истории и возвращает тренера в главное меню.

## Этап 3. Модуль «Аладдин и сокровища корта» (Сбор мячей)

### 3.1. Интерфейс сбора
* Экран открывается в любой момент по отдельной кнопке.
* Список только присутствующих детей: у каждого текущий счет сбора равен 0.
* Крупные кнопки быстрого набора: +1, +5, +10 и возможность ручной корректировки.
* Сквозной счетчик «Золотая казна тренировки» (сумма собранного всеми детьми за все сборы).

### 3.2. Логика фиксации и расчет рейтинга
* Кнопка «В казну султана»:
  * Определение победителя текущего сбора («Аладдин на ковре-самолете»).
  * Плюсование собранных мячей в сквозную копилку `aladdin_vault`.
  * Начисление рейтинговых очков в общую корзину дня пропорционально полезности.

### 3.3. Мгновенная генерация медиа
* **Canvas-арт (Ковер-самолет):**
  * Динамический рендеринг картинки: волшебный ковер-самолет с фото победителя раунда, гора золотых мячей и надпись рекорда.
* **Telegram Bot API:**
  * Отправка сформированной картинки и текста квеста в родительский канал через один запрос к Bot API.

## Этап 4. Модуль «Секундомер с контролем ошибок» (Penalty Timer)

### 4.1. Логика интерфейса секундомера
* Режим индивидуального заезда (карточка стартующего на весь экран).
* Кнопка СТАРТ запускает высокоточный таймер на `requestAnimationFrame` с долями секунд.
* Крупная красная кнопка «+1 Ошибка / Штраф» для тренера с характерным предупреждающим звуком.
* Кнопка СТОП останавливает таймер.

### 4.2. Математика штрафа и ранжир
* Задание штрафной цены за 1 ошибку (по умолчанию +2 сек).
* Формула: Итоговое время = Чистое время + (Ошибки * Штраф).
* Формирование таблицы заездов группы: сортировка от наименьшего времени к наибольшему.
* Конвертация занятых мест в турнирные баллы дня.

## Этап 5. Модуль «Однорукий бандит» (Slot Machine & Джекпот)

### 5.1. Интерфейс игрового автомата
* Экран выбора игрока (подбежал -> нажал свое фото).
* Пульт ввода попаданий из мишеней: кнопки 0, 1, 2, 3, 4, 5.
* Виртуальный рычаг автомата или большая кнопка «КРУТИТЬ».
* 3 вертикальных анимированных барабана.

### 5.2. Логика ветвления
* **При результате 5 из 5 (ДЖЕКПОТ):**
  * Барабаны останавливаются на победной комбинации 👑 | 👑 | 👑.
  * Звуки фанфар и звон монет через Web Audio.
  * Canvas-генератор конфетти и золотого дождя поверх экрана.
  * Максимальные очки в копилку дня без штрафных заданий.
* **При результате 0-4 попадания (Барабан ОФП):**
  * Барабан 1: Число повторений (3, 5, 7, 10).
  * Барабаны 2 и 3: Тип упражнения (Прыжки кенгуру, Лягушка, Приседания, Отжимания).
  * Звук механической трещотки спиц барабана.
  * Остановка на случайном веселом упражнении.
  * Начисление очков за фактические попадания в корзину дня.

## Этап 6. Модуль «Экспертная машина: Техосмотр роботов» (Peer Review)

### 6.1. Подготовка диагностической карты
* Банк 10 биомеханических критериев (точка удара, проводка, сгиб коленей, ранний замах, баланс корпуса, выход из удара и др.).
* Выбор 3 фокусных критериев на сегодняшнюю серию перед стартом.
* Назначение пары: «Пилот робота» (бьющий игрок) и «Главный инженер» (ученик-эксперт).

### 6.2. Рабочее место эксперта
* Крупные кнопки учета попаданий: 🎯 Попадание и ❌ Промах (серия из 10 попыток).
* 3 тумблера фиксации ошибок техники: при каждом нарушении инженер тапает соответствующий тумблер.

### 6.3. Итоговый техпаспорт
* Выпуск диагностической карточки:
  * Процент точности попаданий.
  * Стабильность узлов робота (перечень допущенных погрешностей).
  * Начисление баллов пилоту за серию.
  * Начисление фиксированного бонуса эксперту за судейство.

## Этап 7. Генеральный агрегатор, Пьедестал и Медиа-центр

### 7.1. Финал дня (Построение)
* Кнопка «Завершить тренировку»:
  * Суммирование баллов со всех пройденных блоков (счетчики, секундомеры, сбор мячей, бандит, экспертная машина).
  * Построение генерального пьедестала (1, 2, 3 место и лауреаты номинаций).
  * Объявление победителей в номинациях: «Абсолютный лидер дня», «Султан золотых мячей (Аладдин)», «Главный инженер».

### 7.2. Генератор Stories (Canvas 1080x1920)
* Рендеринг вертикального плаката:
  * Брендированная плашка группы.
  * Пьедестал с реальными фото детей на ступенях почета.
  * Итоговая инфографика тренировки.
  * Кнопка «Поделиться» (Web Share API на iPad).

### 7.3. Интеграция с Telegram Bot API
* Настройка токена бота и ID родительского канала/чата.
* Форматированный пост с итогами дня, текстовой статистикой и прикрепленной графической карточкой подиума.
