# Теннисный Полигон (Tennis Pro)

Автономный цифровой комплекс тренера по теннису для прямого управления тренировкой на корте (целевые устройства: iPad Pro, MacBook).

---

## 1. Главные правила проекта (Кодекс разработки)

1. **Правило чистого стола:** Никаких случайных файлов в корне. Все новые материалы сначала попадают в `01_Входящие`.
2. **Один шаг за раз:** Работаем строго над одним модулем/файлом. Не переходим к следующему, пока текущий не проверен.
3. **100% Offline-first:** Приложение обязано работать в Safari на iPad без подключения к интернету. Данные сессий и участников сохраняются исключительно локально (`localStorage`).
4. **Контрастность и эргономика:** Все элементы управления рассчитываются на работу на солнце и быстрые нажатия на корте (крупные тач-зоны, четкий отклик).
5. **Безопасная фиксация:** Любые утвержденные изменения фиксируются в Git связкой:
   `git add . && git commit -m "тип(область): описание" && git push origin main`

## 3. Модули комплекса

1. **Ростер и Сессия:** Чекин присутствующих (2–8 детей), профили с фото/звуками.
2. **Табло касаний (Matrix Counter):** Скоростной подсчет с цветовыми вспышками и звуком.
3. **«Аладдин и сокровища корта»:** Сбор мячей в сквозную казну дня.
4. **Секундомер со штрафами:** Заезды/полоса препятствий с фиксацией ошибок на лету.
5. **«Однорукий бандит»:** Прием серий ударов, джекпот и барабан ОФП-заданий.
6. **«Экспертная машина»:** Взаимная оценка техники ударов по 3 биомеханическим критериям.
7. **Итоги дня и медиа-центр:** Генерация карточек Stories (1080×1920) и отчет в Telegram.
